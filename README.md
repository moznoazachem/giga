# Гига

Диктовка голосом для macOS на модели [GigaAM v3](https://github.com/salute-developers/GigaAM) от Сбера — открытой SOTA-модели распознавания русской речи. Точнее Whisper на русском, сама расставляет пунктуацию и заглавные, работает **полностью локально** — звук не покидает твой компьютер.

**Зажал клавишу → говоришь → отпустил → текст с пунктуацией появился там, где курсор.** В любом приложении.

## Что внутри

- `Гига.app` — приложение в строке меню (Swift): перехват клавиши-рации, запись с микрофона, вставка текста
- `server/` — локальный сервер распознавания (Python + GigaAM, OpenAI-совместимый API на `127.0.0.1:8737`)
- `install.sh` — установка серверной части в `~/.giga`

## Установка

Понадобятся [Homebrew](https://brew.sh), ffmpeg и Python 3.10–3.12:

```bash
brew install ffmpeg python@3.12
```

Дальше:

```bash
git clone <этот-репозиторий>
cd giga-app
./install.sh          # ставит серверную часть в ~/.giga
./build.sh            # собирает Гига.app в build/ (нужен Xcode или CLT)
open build/Гига.app
```

Либо возьми готовое приложение из [Releases](../../releases) — тогда нужен только `install.sh`. При первом открытии скачанного приложения macOS предупредит о неизвестном разработчике: правый клик по приложению → **Open** → **Open** (один раз).

## Первый запуск

Гига попросит три разрешения (все обязательны):

1. **Input Monitoring** — видеть клавишу-рацию
2. **Микрофон** — записывать голос
3. **Accessibility** — вставлять текст (нажимать ⌘V за тебя)

Каждый раз включай тумблер «Гига» в открывшихся настройках — **через системный запрос, не через «+»**. При первой диктовке модель (~450 МБ) скачается с CDN Сбера автоматически.

## Использование

- **Зажми правый ⌘** (клавиша меняется в меню) → говори → отпусти → текст вставится
- Иконка в строке меню: волна — готова; красная пляшет — запись; точки — распознаёт
- Меню по клику: запись мышкой, выбор клавиши, автозапуск при входе

## Ограничения

- Русский язык (модель заточена под него; английскую речь пишет кириллицей)
- Интернет нужен один раз — скачать модель, дальше офлайн
- CLI-бонус: `~/.giga/transcribe.py файл.mp3` — транскрибация любого аудиофайла
